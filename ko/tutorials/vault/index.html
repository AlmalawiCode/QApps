Vault — Warranty Manager 튜토리얼

영수증 스캔, 보증 관리, 데이터를 안전하게 백업하는 방법을 알아보세요.

시작하기

  1. 구매 추가

    추가를 탭하고 종이 영수증을 스캔하거나, QR 코드를 읽거나, 기존 이미지나 PDF를 가져오세요.

  2. 세부 정보 입력

    매장, 구매일, 제품을 추가하고 제품마다 보증 기간을 지정하세요.

  3. 보증 설정

    보증 기간을 입력하면 Vault가 만료 전에 알려 드립니다.

  4. 매장 위치 저장

    원하면 매장 위치를 저장해 두고 나중에 지도 앱에서 다시 열 수 있습니다.

  5. 데이터 백업

    비밀번호로 보호되는 암호화 백업을 만들고 안전한 곳에 보관하세요.

팁

  • WhatsApp, Gmail, 파일에서 PDF나 사진을 Vault로 바로 공유해 즉시 정리하세요.
  • 보증 보고서를 한꺼번에 PDF로 내보내 인쇄하거나 보내세요.
  • 평생 이용권은 영수증 3개(각 제품 1개)라는 무료 제한을 없애 줍니다.

자주 묻는 질문

데이터는 어디에 저장되나요?

기기에 저장됩니다. Vault는 로컬 우선 방식이며 영수증을 어떤 서버에도 업로드하지 않습니다.

알림은 어떻게 작동하나요?

Vault는 보증 만료일 전에 기기에서 로컬 알림을 예약합니다.

백업은 안전한가요?

백업은 직접 설정한 비밀번호를 사용해 AES-256으로 암호화됩니다. 비밀번호를 안전하게 보관하세요. 복구할 수 없습니다.

평생 이용권이란 무엇인가요?

한 번의 일회성 구매로 영수증과 제품을 무제한으로 이용할 수 있습니다. 구독은 없습니다.
