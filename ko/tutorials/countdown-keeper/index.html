Countdown Keeper 튜토리얼

이벤트 추가, 알림, 반복 날짜, 내장 날짜 도구 사용법을 알아보세요.

시작하기

  1. 첫 이벤트 추가

    + 버튼을 탭하고, 제목을 입력한 뒤 날짜(필요하면 시간도)를 선택하세요.

  2. 달력 선택

    날짜를 계산하고 표시할 달력으로 그레고리력 또는 히즈라력을 선택하세요.

  3. 알아보기 쉽게

    이벤트에 색상과 이모지를 지정하거나 내 사진을 첨부하고, 메모를 추가하세요.

  4. 알림 켜기

    원하면 정시, 하루 전 또는 일주일 전 알림을 켤 수 있습니다.

  5. 중요한 것은 고정

    중요한 이벤트를 고정하면 목록 맨 위에 유지됩니다.

팁

  • 이벤트 편집 화면에서 매월 반복을 설정하면 반복되는 날짜를 자동으로 관리할 수 있습니다.
  • ‘도구’ 탭에서 나이 계산기, 날짜 차이, 은퇴일 예측을 이용하세요.
  • 이벤트를 JSON 파일로 내보내면 직접 완전히 관리하는 개인 백업이 됩니다.

자주 묻는 질문

인터넷 연결이 필요한가요?

아니요. Countdown Keeper는 완전히 오프라인으로 작동하며, 이벤트는 기기에 보관됩니다.

삭제한 이벤트는 어떻게 복구하나요?

휴지통을 열고 영구 삭제되기 전에 복원하세요.

히즈라력으로 날짜를 표시할 수 있나요?

네. 히즈라력(움무 알쿠라) 또는 그레고리력으로 날짜를 볼 수 있고, 히즈라력 날짜로 이벤트를 반복할 수도 있습니다.

도움이 더 필요하신가요? Countdown Keeper 지원을 방문하거나 이메일을 보내 주세요.
